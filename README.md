Exploratory Data Analysis on the Titanic training dataset (train.csv) — visual and statistical exploration of passenger survival patterns using Python, Pandas, Matplotlib, and Seaborn. # Titanic EDA

Exploratory Data Analysis on the Titanic training dataset (train.csv) from Kaggle's 
"Titanic: Machine Learning from Disaster" competition.

## Objective
Extract insights on passenger survival using visual and statistical exploration.

## Tools
Python — Pandas, Matplotlib, Seaborn

## Key Findings
- Sex was the strongest predictor of survival (women ~74% vs men ~19%)
- Passenger class strongly influenced outcomes (1st class ~63% vs 3rd class ~24%)
- Fare and Pclass showed the strongest correlations with survival
- Age and Cabin had significant missing data (~20% and ~77% respectively)

## Dataset
Source: [Kaggle Titanic Competition](https://www.kaggle.com/c/titanic/data)
